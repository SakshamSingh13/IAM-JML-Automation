# SailPoint IdentityIQ: Joiner-Mover-Leaver (JML) Lifecycle Automation

An enterprise-ready lifecycle orchestration pipeline configured natively within **SailPoint IdentityIQ (8.1)**. This project demonstrates automated user lifecycle transitions triggered from an authoritative HR flat-file data source.

## 🛠️ Configuration & Implementation

1. **Authoritative Feed Definition (`/config/HR_Source_System.xml`)**
   - Establishes a native `DelimitedFile` connector mapping source attributes directly onto Identity Cubes using `EmployeeID` as the primary correlation key.

2. **JML Lifecycle Triggers (`/config/JML_*_Event.xml`)**
   - Configures native Identity Attribute Change event triggers that route identities to dedicated out-of-the-box business processes:
     - **Joiner Event**: Fires the `Lifecycle Event - Joiner` workflow for immediate account creation.
     - **Mover Event**: Captures department adjustments and invokes `Lifecycle Event - Manager Transfer`.
     - **Leaver Event**: Catches status drops and targets the `Lifecycle Event - Leaver` workflow for rapid disablement.

3. **Dynamic Hierarchy Resolver (`/config/JML_Manager_Correlation_Rule.xml`)**
   - Utilizes a specialized BeanShell **Manager Correlation Rule** to dynamically evaluate supervisor text strings and auto-instantiate operational stub manager identities on-the-fly.
